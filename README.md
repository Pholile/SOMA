##  Project Overview
Edu Share is a textbook exchange platform designed for African universities.  
It empowers students to **buy, sell, and trade textbooks securely** while promoting accessibility and affordability.

---

##  Core Features
- <span style="color:orange;">User Authentication & Role-based Authorization</span> (Buyer, Seller, Admin)
- <span style="color:blue;">CRUD operations</span> for textbook listings with image upload and metadata
- Offers & Transactions workflow (make, accept/reject, complete)
- Reviews & Trust score system
- Wanted Ads functionality
- Search, filtering, sorting, pagination, and personalized dashboards

---

##  Tech Stack
- **Frontend**: Blazor, Razor Components  
- **Backend**: ASP.NET Core (.NET 8+), C#  
- **Database**: SQL Server, Entity Framework Core  
- **Hosting**: Microsoft Azure App Services  
- **Version Control**: GitHub (feature branches, 15+ commits, README, screenshots)

---

##  System Architecture
- Layered architecture: **UI → Services → Data Layer**  
- Dependency Injection for modular design  
- Async/await for database operations  
- Business logic handled in service layer  

---

##  Database Design
- EF Core migrations  
- Proper table relationships & constraints  
- Seeded test data  
- Normalized schema ensuring integrity
